JavaScript API

Complete reference for all exports from the markup-plus-js package. Includes rendering functions, AST classes, type aliases, and utility constants.

Quick reference

This page is a lookup table. For tutorials and examples, see the JavaScript API Guide.

Main Import

Rendering Functions

toHTML(source, options?)

Convert Markup+ source to a complete HTML document.

Parameter Type Description
sourcestringMarkup+ content
optionsRenderOptionsOptional render configuration

Returns: string — Complete HTML document

toHTMLAsync(source, options?)

Async version of toHTML with support for @import from the file system.

Returns: Promise<string>

renderBody(source, options?)

Render only the body content (no <html>, <head>, or <body>).

Returns: string — Body HTML

renderFragment(source, options?)

Render a scoped fragment. CSS is isolated so it won't conflict with the host page.

Returns: string — Scoped fragment HTML

parse(source)

Parse Markup+ source into an AST Document.

Returns: Document
