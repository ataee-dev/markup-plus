CDN Usage

Use Markup+ JS directly in the browser via a CDN. No npm, no build step, no bundler — just a script tag.

When to use CDN

CDN is ideal for: quick prototypes, static HTML pages, documentation sites, CodePen/JSFiddle demos, and chatbot widgets. For production apps with build tools, prefer npm installation.

Quick start

Add a single script tag to your HTML, then call MarkupPlus.toHTML():

Minimal CDN example

Available CDNs

Both jsDelivr and unpkg serve the package automatically from npm. No registration required.

jsDelivr (recommended)

Fastest global CDN, supports ESM, has automatic version pinning and fallbacks.

jsDelivr 
<script src="https://cdn.jsdelivr.net/npm/markup-plus-js@0.6.4/dist/markup-plus.min.js"></script>

unpkg

Serves files directly from npm. Useful as an alternative or fallback.

unpkg 
<script src="https://unpkg.com/markup-plus-js@0.6.4/dist/markup-plus.min.js"></script>

ESM via jsDelivr

If you prefer ES modules, jsDelivr has an auto-generated ESM bundle with the +esm suffix:

ESM import 
<script type="module">
  import { toHTML, renderFragment } from 'https://cdn.jsdelivr.net/npm/markup-plus-js@0.6.4/+esm';

  document.body.innerHTML = toHTML('# Hello from ESM');
</script>

Version pinning

Always pin the version in production. Otherwise a future breaking change could silently break your page.

URL pattern Behavior Use case
.../markup-plus-js@0.6.4/... Exact version Production — recommended
.../markup-plus-js@0.6/... Latest 0.6.x Patch updates only
.../markup-plus-js@0/... Latest 0.x.x Minor updates (risky)
.../markup-plus-js/... Latest (any version) Prototyping only
Warning

Do not use unpinned URLs (.../markup-plus-js/...) in production. A future release could break your page without warning.

Available functions in the browser

Once loaded, the global MarkupPlus object exposes the same API as the npm package:

Function Purpose
MarkupPlus.toHTML(source, options)Full HTML page
MarkupPlus.renderBody(source, options)Body only (no <html>)
MarkupPlus.renderFragment(source, options)Fragment for chatbots
MarkupPlus.parse(source)Parse to AST
MarkupPlus.versionVersion string

Common patterns

Render a full page

Full page render 
const source = `
# Hello, Markup+

This is **bold** and this is *italic*.

@note
Everything here was rendered client-side.
@end
`;

const html = MarkupPlus.toHTML(source, {
  title: 'My Page',
  theme: 'dark',
  includeCDN: true,
});

document.open();
document.write(html);
document.close();

Embed into an existing page

Embed body only 
const mup = `
## Rendered inline

This section was written in Markup+ and injected into an existing page.
`;

document.getElementById('content').innerHTML =
  MarkupPlus.renderBody(mup);

Fetch and render a remote .mup file

Fetch remote file 
async function renderFromUrl(url, target) {
  const res = await fetch(url);
  if (!res.ok) throw new Error('HTTP ' + res.status);
  const source = await res.text();
  document.getElementById(target).innerHTML =
    MarkupPlus.renderBody(source);
}

renderFromUrl('./content/readme.mup', 'output');

Chatbot fragment

renderFragment for chatbots 
const botResponse = `
# Answer

Here is a **formatted** answer from the bot.

@tip
This is a tip block.
@end

\`\`\`javascript
console.log("with code");
\`\`\`
`;

document.getElementById('chat').innerHTML =
  MarkupPlus.renderFragment(botResponse, {
    includeScripts: true,
    includeCDNScripts: true,
  });

CDN libraries for rich content

Markup+ can include CDN scripts for rich content. When you call toHTML() with includeCDN: true, the output HTML automatically loads:

Library Purpose CDN
Prism.js Syntax highlighting for code blocks cdn.jsdelivr.net
Chart.js Bar, line, pie, doughnut charts cdn.jsdelivr.net
KaTeX Math formulas ($...$ and $$...$$) cdn.jsdelivr.net
Tip

If your page is used offline, set includeCDN: false and load Prism, Chart.js, and KaTeX yourself from a local copy.

Browser support

The CDN build works in all modern browsers:

  • Chrome / Edge 90+
  • Firefox 88+
  • Safari 14+
  • Opera 76+

For older browsers, transpile with a bundler or use polyfills.

Troubleshooting

Problem Cause Fix
MarkupPlus is not defined Script tag failed to load, or called too early Check network tab. Use window.addEventListener('load', ...)
Charts don't render includeCDN: false Set includeCDN: true in options
Math shows as raw text KaTeX not loaded Ensure includeCDN: true
Old version cached CDN cache Pin the version explicitly: @0.6.4
CORS error on fetch() Opening file via file:// Use a local server: python -m http.server
