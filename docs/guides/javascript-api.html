JavaScript API

Complete reference for the markup-plus-js public API — rendering functions, parsing, CSS helpers, RTL utilities, and AST classes.

TypeScript support

All functions and types are fully typed. Import types alongside functions for full IntelliSense support. See TypeScript guide.

Importing

Main entry point — most users only need this:

Basic import 
import {
  toHTML,
  toHTMLAsync,
  renderBody,
  renderFragment,
  parse,
} from 'markup-plus-js';

Subpath imports for advanced use cases:

Subpath imports 
// Parser only
import { parse } from 'markup-plus-js/parser';

// Renderer only
import { renderBody } from 'markup-plus-js/renderer';

// AST classes
import { Document, Heading } from 'markup-plus-js/ast';

// Base CSS string
import baseCSS from 'markup-plus-js/base-css';

Rendering functions

toHTML(source, options?)

Converts a Markup+ source string into a complete HTML document (with <html>, <head>, <body>):

toHTML 
import { toHTML } from 'markup-plus-js';

const html = toHTML('# Hello World', {
  title: 'My Page',
  theme: 'dracula',
  autoDarkMode: true,
});

console.log(html);
// ...

Signature:

TypeScript signature 
function toHTML(
  source: string,
  options?: RenderOptions
): string;

toHTMLAsync(source, options?)

Async version with support for @import directives that need file system access:

toHTMLAsync 
import { toHTMLAsync } from 'markup-plus-js';

const source = `
@import "header.mup"

# Main Content

More content here.
`;

const html = await toHTMLAsync(source, {
  baseDir: './docs'
});

Signature:

TypeScript signature 
function toHTMLAsync(
  source: string,
  options?: RenderOptions
): Promise<string>;

renderBody(source, options?)

Renders only the body content (no <html>, <head>, or <body> wrapper). Ideal for embedding into existing pages:

renderBody 
import { renderBody } from 'markup-plus-js';

const body = renderBody('# Hello\n\nWelcome!');
document.getElementById('content').innerHTML = body;

Signature:

TypeScript signature 
function renderBody(
  source: string,
  options?: RenderOptions
): string;

renderFragment(source, options?)

Renders a scoped fragment suitable for chatbots and widgets. CSS is scoped so it doesn't interfere with the host page:

renderFragment 
import { renderFragment } from 'markup-plus-js';

const response = `
# Answer

Here is a **formatted** answer.

@tip
This is a tip.
@end
`;

const fragment = renderFragment(response, {
  theme: 'light',
  scoped: true,
  includeScripts: true,
  includeCDNScripts: true,
});

document.getElementById('chat').innerHTML = fragment;

Signature:

TypeScript signature 
function renderFragment(
  source: string,
  options?: RenderOptions
): string;

parse(source)

Parses a Markup+ source string into an AST document. Useful for building tooling around the language:

parse 
import { parse } from 'markup-plus-js';

const doc = parse('# Hello\n\nWorld');

console.log(doc.children);
// [
//   Heading { level: 1, text: 'Hello', slug: 'hello' },
//   Paragraph { text: 'World' }
// ]

console.log(doc.meta);
// { title: 'Hello' }

Signature:

TypeScript signature 
function parse(source: string): Document;

CSS API

buildCSS(customCSS, options)

Build the final CSS by combining base CSS, theme CSS, and custom CSS:

buildCSS 
import { buildCSS } from 'markup-plus-js';

const css = buildCSS('body { font-size: 18px; }', {
  theme: 'dracula'
});

console.log(css.length); // length in characters

getThemeCSS(theme)

Get the CSS string for a specific theme:

getThemeCSS 
import { getThemeCSS } from 'markup-plus-js';

const draculaCSS = getThemeCSS('dracula');

registerTheme(name, css)

Register a custom theme at runtime:

registerTheme 
import { registerTheme } from 'markup-plus-js';

registerTheme('my-brand', `
  :root {
    --mup-accent: #ff6b6b;
    --mup-bg: #1a1a2e;
  }
`);

// Now usable as theme
const html = toHTML('# Hello', { theme: 'my-brand' });

Express server

Express integration 
import express from 'express';
import { toHTMLAsync } from 'markup-plus-js';

const app = express();

app.get('/doc', async (req, res) => {
  const source = await fs.readFile('doc.mup', 'utf8');
  const html = await toHTMLAsync(source, {
    baseDir: './docs',
    theme: 'github',
  });
  res.type('html').send(html);
});

app.listen(3000);

React component

React component 
import { useMemo } from 'react';
import { renderBody } from 'markup-plus-js';

function MarkupPlus({ source, theme = 'light' }) {
  const html = useMemo(
    () => renderBody(source, { theme }),
    [source, theme]
  );

  return <div dangerouslySetInnerHTML={{ __html: html }} />;
}

export default MarkupPlus;

Custom renderer

Custom renderer using AST 
import { parse } from 'markup-plus-js';
import { Heading, Paragraph } from 'markup-plus-js/ast';

function extractHeadings(source) {
  const doc = parse(source);
  return doc.children
    .filter((node) => node instanceof Heading)
    .map((h) => ({ level: h.level, text: h.text }));
}

const source = '# Title\n\n## Section\n\nContent';
console.log(extractHeadings(source));
// [{ level: 1, text: 'Title' }, { level: 2, text: 'Section' }]
