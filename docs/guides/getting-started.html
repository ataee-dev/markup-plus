Introduction

What is Markup+, why does it exist, and what makes it different from Markdown.

What is Markup+?

Markup+ is a modern markup language that extends the familiar Markdown syntax with features for building documentation, reports, blogs, technical pages, and interactive HTML documents.

Everything you know from Markdown still works. You can progressively add features such as variables, conditions, loops, components, charts, mathematical formulas, tabs, alerts, galleries, imports, and RTL-aware rendering.

Why Markup+?

Markdown is excellent for structured text, but many projects eventually need features that are outside traditional Markdown:

  • Reusable values — instead of duplicating text, define variables once and reference them everywhere.
  • Logic — show different content based on conditions or loop over data.
  • Rich content — charts, math formulas, tabs, and accordions without writing raw HTML.
  • RTL-aware output — automatic right-to-left detection for Persian, Arabic, Hebrew, and Urdu.

Markup+ keeps the readable markup style while adding a programmable document layer.

What can you build with it?

  • Documentation — API docs, user guides, tutorials.
  • Blogs — technical articles with code, charts, and math.
  • Reports — data-driven reports with charts and tables.
  • Academic content — papers with math formulas.
  • Persian and Arabic content — automatic RTL support.
  • Static sites — a lightweight alternative to heavy frameworks.
  • Chatbot responses — rich formatted answers via fragment rendering.

The Markup+ ecosystem

Markup+ has two official implementations:

Implementation Package Repository
JavaScript markup-plus-js ataee-dev/markup-plus-js
Python markup-plus ataee-dev/markup-plus

The source language is .mup — the same file works with both implementations, producing equivalent HTML output.
