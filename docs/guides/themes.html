Themes

Markup+ ships with 12 built-in themes. Each theme controls colors, fonts, shadows, and visual styling of the generated HTML. The same themes work across both JavaScript and Python implementations.

Language-agnostic

Themes are part of the Markup+ language, not a specific implementation. Use theme: 'dracula' in JavaScript, theme="dracula" in Python, or --theme dracula in the CLI — all produce identical output.

Using themes in JavaScript

Set the theme via the theme option in toHTML:

Basic usage 
import { toHTML } from 'markup-plus-js';

const html = toHTML('# Hello', {
  theme: 'dracula'
});

Or use a shortcut for common themes:

Shortcuts 
mup-js file.mup --dark       # Short for --theme dark
mup-js file.mup --light      # Short for --theme light
mup-js file.mup -d           # Same as --dark
mup-js file.mup -l           # Same as --light

Using themes in Python

Python usage 
from markup_plus import to_html

html = to_html("# Hello", theme="dracula")

Using themes in the CLI

CLI usage 
# JavaScript
mup-js file.mup --theme dracula

# Python
mup file.mup --theme dracula

Programmatic theme API

The JavaScript implementation exposes additional theme utilities:

Register a custom theme

registerTheme 
import { registerTheme, toHTML } from 'markup-plus-js';

registerTheme('my-brand', `
  :root {
    --mup-accent: #ff6b6b;
    --mup-bg: #1a1a2e;
    --mup-text: #eaeaea;
  }
`);

const html = toHTML('# Hello', { theme: 'my-brand' });

List available themes

listThemes 
import { listThemes, VALID_THEMES } from 'markup-plus-js';

console.log(listThemes());
// ['light', 'dark', 'minimal', 'github', ...]

console.log(VALID_THEMES);
// Same array, exported as constant

Validate a theme name

isValidTheme 
import { isValidTheme } from 'markup-plus-js';

isValidTheme('dracula');    // true
isValidTheme('Dracula');    // false (case-sensitive)
isValidTheme('unknown');    // false

Get theme CSS

getThemeCSS 
import { getThemeCSS } from 'markup-plus-js';

const css = getThemeCSS('dracula');
console.log(css.length); // length in characters

Auto dark mode

JavaScript v0.6.4 supports automatic dark mode based on the user's OS preference:

Auto dark 
const html = toHTML(source, {
  theme: 'light',
  autoDarkMode: true,
});

When autoDarkMode: true, the output uses:

  • light theme by default
  • dark theme when the user's OS is in dark mode
  • Uses the CSS prefers-color-scheme media query

Time-based themes

JavaScript v0.6.4 also supports switching themes based on the time of day:

Time-based theme 
const html = toHTML(source, {
  timeBasedTheme: {
    light: 'github',
    dark: 'dracula',
    dayStart: 6,     // 6 AM
    nightStart: 18,  // 6 PM
  }
});

Custom CSS

Every theme supports CSS variable overrides. Pass custom CSS to toHTML:

Custom CSS (JS) 
const html = toHTML(source, {
  theme: 'light',
  customCSS: `
    :root {
      --mup-accent: #ff6b6b;
      --mup-bg: #1a1a2e;
      --mup-text: #eaeaea;
    }
  `
});
Custom CSS (Python) 
from markup_plus import to_html

html = to_html(
    source,
    theme="light",
    custom_css="""
        :root {
            --mup-accent: #ff6b6b;
            --mup-bg: #1a1a2e;
            --mup-text: #eaeaea;
        }
    """
)
Custom CSS (CLI) 
# JavaScript
mup-js file.mup --css custom.css

# Python
mup file.mup --css custom.css

Creating a custom theme

A theme is just a CSS string. Create one with these conventions:

Custom theme example 
/* my-theme.css */

:root {
  --mup-accent: #ff6b6b;
  --mup-accent-hover: #e94a4a;
  --mup-bg: #fdf6f0;
  --mup-bg-soft: #f9ede4;
  --mup-text: #2d1f1a;
  --mup-text-soft: #5c4a42;
  --mup-muted: #8b7a70;
  --mup-border: #e8d8cc;
  --mup-font: 'Inter', -apple-system, sans-serif;
  --mup-font-size: 17px;
  --mup-max-width: 800px;
}

/* Optional: element-specific styles */

h1 {
  color: var(--mup-accent);
  font-weight: 900;
}

blockquote {
  border-left: 4px solid var(--mup-accent);
  background: var(--mup-bg-soft);
  border-radius: 8px;
  padding: 16px 20px;
}

Then use it in your document:

Use custom theme 
import { readFileSync } from 'fs';
import { toHTML } from 'markup-plus-js';

const themeCSS = readFileSync('./my-theme.css', 'utf8');

const html = toHTML(source, {
  customCSS: themeCSS
});

Common errors

Problem Cause Fix
Theme not applied Theme name typo or wrong case Use lowercase: 'dracula' not 'Dracula'
Unknown theme Invalid theme name Check the list of 12 valid themes
Custom CSS not loading Wrong option name JS: customCSS, Python: custom_css
Colors wrong after custom CSS CSS variable name typo Use --mup-* prefix, case-sensitive
Theme missing in Python Older Python version Update: pip install --upgrade markup-plus
