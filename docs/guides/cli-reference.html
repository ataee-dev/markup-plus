CLI Reference

Complete command-line reference for both JavaScript (mup-js) and Python (mup) implementations. The two CLIs share the same syntax, options, and behavior.

Cross-platform

mup-js works on Windows, macOS, and Linux via Node.js. mup works the same way via Python. Both produce identical HTML output.

Installation

Install either implementation globally:

Install 
# JavaScript
npm install -g markup-plus-js

# Verify
mup-js --version
# Markup+ JS v0.6.4
# Python
pip install markup-plus

# Verify
mup --version
# Markup+ v0.6.4

Convert a file

Convert a .mup file to a complete HTML document:

Basic convert 
mup-js hello.mup
# Creates hello.html in the same directory
mup hello.mup
# Creates hello.html in the same directory

Output can be customized with flags:

Convert with options 
# Custom output path
mup-js input.mup --output build/index.html
mup-js input.mup -o build/index.html

# Dark theme
mup-js report.mup --dark
mup-js report.mup -d

# Specific theme
mup-js report.mup --theme dracula

# Force RTL
mup-js persian.mup --rtl

# Custom CSS
mup-js doc.mup --css custom.css
# Custom output path
mup input.mup --output build/index.html
mup input.mup -o build/index.html

# Dark theme
mup report.mup --dark
mup report.mup -d

# Specific theme
mup report.mup --theme dracula

# Force RTL
mup persian.mup --rtl

# Custom CSS
mup doc.mup --css custom.css

Watch mode

Rebuild automatically on every file save. Press Ctrl+C to stop:

Watch 
mup-js watch hello.mup

# Output:
# Watching for changes...
# Input:  hello.mup
# Output: hello.html
# Press Ctrl+C to stop.

# After save:
# [time] Change detected, rebuilding...
# Rebuilt -> hello.html
mup watch hello.mup

# Output:
# Watching for changes...
# Input:  hello.mup
# Output: hello.html
# Press Ctrl+C to stop.

# After save:
# [time] Change detected, rebuilding...
# Rebuilt -> hello.html

Batch conversion

Batch convert (Windows) 
:: Windows
for %f in (docs\*.mup) do mup-js "%f" -o "build\%~nf.html"
:: Windows
for %f in (docs\*.mup) do mup "%f" -o "build\%~nf.html"
Batch convert (macOS/Linux)

for f in docs/*.mup; do
  mup-js "$f" -o "build/$(basename "$f" .mup).html"
done
# macOS / Linux
for f in docs/*.mup; do
  mup "$f" -o "build/$(basename "$f" .mup).html"
done

Using in build scripts

Add Markup+ commands to package.json:

package.json scripts 
{
  "scripts": {
    "docs:build": "mup-js docs/index.mup -o build/index.html",
    "docs:watch": "mup-js watch docs/index.mup -o build/index.html",
    "docs:check": "mup-js check docs/index.mup",
    "docs:all": "npm run docs:check && npm run docs:build"
  }
}

For Python projects, use a Makefile or shell script:

Makefile 
build:
	mup docs/index.mup -o build/index.html

watch:
	mup watch docs/index.mup -o build/index.html

check:
	mup check docs/index.mup

.PHONY: build watch check

Troubleshooting

Problem Cause Fix
mup-js: command not found Global bin not in PATH Use npx markup-plus-js, or add npm global bin to PATH
mup: command not found Python scripts not in PATH Use python -m markup_plus, or reinstall with pip
File not found Wrong path or working directory Use absolute paths or cd to the correct folder
Watch mode doesn't rebuild Editor saves atomically (e.g., Vim with backup) Save again, or configure editor for in-place saves
Output is empty Input file is empty or only comments Run mup-js check file.mup
Permission denied Trying to write to a protected folder Choose a user folder, or run as administrator
Slow performance Very large file or many charts Split with @import, or reduce chart data
