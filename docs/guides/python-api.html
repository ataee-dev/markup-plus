Python API

Complete reference for the markup-plus Python package. Markup+ is a language-agnostic markup language — the same .mup files produce identical HTML whether rendered by the JavaScript or Python implementation.

Language-agnostic by design

Markup+ is not tied to any language. The .mup source format is universal — you can write a document in Python, render it in JavaScript, or vice versa. Both implementations share the same syntax, features, and output.

Markup+ ecosystem

Markup+ has multiple official implementations, all producing the same HTML output from the same .mup files:

Language Package Version Install
JavaScript markup-plus-js 0.6.4 npm install markup-plus-js
Python markup-plus 0.6.1 pip install markup-plus
Which one should I use?

Use the Python implementation if your project is written in Python (Flask, Django, data pipelines). Use the JavaScript implementation if your project is in Node.js, or if you need the most recent features (v0.6.4 includes TypeScript, fragment rendering, and more themes).

to_html()

Converts Markup+ source into a complete HTML document with <html>, <head>, and <body>:

Basic usage 
from markup_plus import to_html

html = to_html("# Hello World")
print(html)
# <!DOCTYPE html><html>...</html>

Signature:

Full signature

    text: str,
    title: str = 'Markup+ Document',
    theme: str = 'light',

    custom_css: str = None,

parse_text()

Parses Markup+ source into an AST Document tree. Useful for building custom tooling, extractors, or analyzers:

Basic usage 
from markup_plus import parse_text

doc = parse_text("# Hello\n\nWorld")

print(doc.children)
# [Heading(level=1, text='Hello', slug='hello'),
#  Paragraph(text='World')]

print(doc.meta)
# {'title': 'Hello'}

Signature:

Signature 
parse_text(text: str) -> Document

Document object

The returned Document has these attributes:

Attribute Type Description

metadictFront matter metadata

footnotesdictFootnote definitions
componentsdictComponent definitions

AST classes

All AST node classes are available in markup_plus.ast:

Import AST classes 
from markup_plus import ast
from markup_plus.ast import Heading, Paragraph, CodeBlock

# Or:
from markup_plus import parse_text
doc = parse_text(source)

for node in doc.children:
    if isinstance(node, Heading):

Theme utilities

The markup_plus.themes module handles CSS loading and building:

Theme utilities 
from markup_plus import themes

# Build final CSS from base + theme + custom
css = themes.build_css(theme="dracula", custom_css=None)

# Load only the base CSS
base = themes.load_base_css()

# Load a custom CSS file
custom = themes.load_custom_css("my-style.css")

Using renderer internals 
from markup_plus import parse_text
from markup_plus import renderer

doc = parse_text("# Hello\n\nWorld")

# Render only the body (no <html> wrapper)
body = renderer.render_ast(doc)
print(body)

# Extract all headings from a document
def extract_headings(source: str):
    doc = parse_text(source)
    return [
        {"level": n.level, "text": n.text}
        for n in doc.children
        if n.__class__.__name__ == "Heading"
    ]

print(extract_headings("# Title\n\n## Section"))

Parser internals

The markup_plus.parser and markup_plus.lexer modules expose lower-level parsing:

Module Purpose
markup_plus.lexerTokenize .mup source into tokens
markup_plus.parserParse tokens into an AST tree
Custom parsing 
from markup_plus import lexer, parser

# Tokenize
source = "# Hello\n\nWorld"
tokens = lexer.Lexer(source).tokenize()
for t in tokens[:5]:
    print(t.type, repr(t.value))

# Parse
doc = parser.parse_text(source)
print(doc.children)

Batch conversion

Batch convert folder 
from pathlib import Path
from markup_plus import to_html

docs_dir = Path("docs")
build_dir = Path("build")
build_dir.mkdir(exist_ok=True)

for mup_file in docs_dir.glob("*.mup"):
    source = mup_file.read_text(encoding="utf-8")
    html = to_html(source, title=mup_file.stem)
    output = build_dir / (mup_file.stem + ".html")
    output.write_text(html, encoding="utf-8")
    print(f"Built: {output}")

AST analysis

Extract all headings 
from markup_plus import parse_text
from markup_plus.ast import Heading, CodeBlock

doc = parse_text(open("docs/index.mup", encoding="utf-8").read())

# All headings
headings = [n for n in doc.children if isinstance(n, Heading)]
for h in headings:
    print(f"{'  ' * (h.level - 1)}{h.text}")

# Count code blocks
code_count = sum(1 for n in doc.children if isinstance(n, CodeBlock))
print(f"Total code blocks: {code_count}")
