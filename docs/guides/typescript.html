TypeScript

The JavaScript implementation of Markup+ ships with complete TypeScript definitions. No @types/ package needed — types are bundled with the package.

Why TypeScript?

Full IntelliSense, autocomplete, and compile-time error checking. Catch mistakes before they reach production.

JavaScript only

TypeScript definitions are available only in the JavaScript implementation (markup-plus-js). The Python implementation uses native type hints instead.
