Installation

Install Markup+ in your environment — JavaScript via npm, browsers via CDN, Python via pip, or run the CLI directly. Then set up your editor for a smooth workflow.

1. Choose your method

Environment Method Best for
Node.js / bundler npm install Apps, build tools, TypeScript projects
Browser (no build) CDN script tag Prototypes, static HTML, CodePen
Python pip install Python scripts, servers, CI pipelines
Command line npm i -g Converting .mup files from a terminal
Source git clone Contributing, patching, local development

2. Requirements

Runtime Minimum version
Node.js 18.0.0 or newer
Python 3.9 or newer
Browsers Chrome 90+, Firefox 88+, Safari 14+, Edge 90+

3. Install via npm (JavaScript)

For Node.js projects, bundlers, and any environment that supports npm.

Install 
npm install markup-plus-js

Or with a package manager of your choice:

Package managers 
# npm
npm install markup-plus-js

# yarn
yarn add markup-plus-js

# pnpm
pnpm add markup-plus-js

# bun
bun add markup-plus-js

Basic usage

index.js 
import { toHTML } from 'markup-plus-js';

const html = toHTML('# Hello World', {
  theme: 'dark',
});

console.log(html);

With TypeScript

Types are bundled — no @types/ package needed.

TypeScript 
import { toHTML, Theme, RenderOptions } from 'markup-plus-js';

const theme: Theme = 'dracula';
const options: RenderOptions = { theme };

const html: string = toHTML('# Hello', options);
console.log(html);

CommonJS

CommonJS 
const { toHTML } = require('markup-plus-js');

const html = toHTML('# Hello');

Subpath imports

The package exposes several subpath entry points for advanced use cases:

Subpaths 
// Main entry (recommended)
import { toHTML } from 'markup-plus-js';

// Parser only
import { parse } from 'markup-plus-js/parser';

// Renderer only
import { renderBody } from 'markup-plus-js/renderer';

// AST classes
import * as ast from 'markup-plus-js/ast';

// Base CSS as a string
import baseCSS from 'markup-plus-js/base-css';

4. Install via CDN (Browser)

No installation needed. Just add a script tag to your HTML page.

index.html 
<script src="https://cdn.jsdelivr.net/npm/markup-plus-js@0.6.4/dist/markup-plus.min.js"></script>

<div id="app"></div>

<script>
  document.getElementById('app').innerHTML =
    MarkupPlus.renderBody('# Hello World');
</script>

For the full guide — including ESM, version pinning, and offline use — see CDN Usage.

5. Install via pip (Python)

The Python implementation produces equivalent HTML output. Use it in Python scripts, servers, or CI pipelines.

Install 
pip install markup-plus

Or in a virtual environment (recommended):

Virtual environment 
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Install
pip install markup-plus

Python usage

example.py 
from markup_plus import to_html

html = to_html("# Hello World", theme="dark")
print(html)

Verify installation

Verify 
python -c "import markup_plus; print(markup_plus.__version__)"

For the full Python API, see the Python API reference.

6. Command-line interface

The CLI is bundled with the npm package. Install it globally to use mup-js from any directory.

Global install 
npm install -g markup-plus-js

Or run it once without installing:

One-off run 
npx markup-plus-js hello.mup

Verify

Verify CLI 
mup-js --version
# Markup+ JS v0.6.4

mup-js --help

Quick CLI example

Convert a file 
# Convert hello.mup to hello.html
mup-js hello.mup

# Watch for changes and rebuild
mup-js watch hello.mup

# Create a new document
mup-js new my-doc

# Validate a file
mup-js check hello.mup

# Initialize a project
mup-js init my-project

For the full CLI reference, see CLI Reference.

9. Your first document

Create a file called hello.mup:

hello.mup 
# Hello, Markup+

This is **bold** and this is *italic*.

@let name = "World"

Hello, {name}!

@note
Markup+ extends Markdown with variables, conditionals, loops, and more.
@end

Convert it:

Convert 
mup-js hello.mup

# Creates hello.html
# Open it in a browser:
# Windows:  start hello.html
# macOS:    open hello.html
# Linux:    xdg-open hello.html

12. Troubleshooting

Problem Cause Fix
npm ERR! 404 Not Found Package name typo Use markup-plus-js (with hyphen and js)
Cannot find module 'markup-plus-js' Install ran in wrong directory Run npm install inside your project folder (where package.json is)
ERR_REQUIRE_ESM Using require() in an ESM-only context Use import, or add "type": "module" to package.json
MarkupPlus is not defined Script tag loaded after your script, or network error Put the CDN script first, and wrap your code in window.addEventListener('load', ...)
pip: command not found Python not installed or pip not in PATH Install Python from python.org and check "Add to PATH"
mup-js: command not found Global install folder not in PATH Use npx markup-plus-js instead, or add npm global bin to PATH
Slow install Network speed Try a different registry: npm install --registry=https://registry.npmjs.org/

13. Editor setup (VS Code)

Markup+ files use the .mup extension. VS Code doesn't know about them out of the box, but a few small tweaks make editing comfortable.

File association

Tell VS Code to open .mup files as Markdown by default:

settings.json 
{
  "files.associations": {
    "*.mup": "markdown"
  }
}

Open Command Palette (Ctrl+Shift+P), search Preferences: Open User Settings (JSON), and add the snippet.

Recommended extensions

Extension Purpose ID
Markdown All in One Shortcuts, TOC, preview yzhang.markdown-all-in-one
markdownlint Style linting DavidAnson.vscode-markdownlint
Prettier Formatting esbenp.prettier-vscode
Code Spell Checker Typo detection streetsidesoftware.code-spell-checker
Live Server Preview generated HTML ritwickdey.LiveServer
Error Lens Inline errors usernamehw.errorlens

Install all at once from the terminal:

Install extensions 
code --install-extension yzhang.markdown-all-in-one
code --install-extension DavidAnson.vscode-markdownlint
code --install-extension esbenp.prettier-vscode
code --install-extension streetsidesoftware.code-spell-checker
code --install-extension ritwickdey.LiveServer
code --install-extension usernamehw.errorlens

Custom snippets

Add snippets for common Markup+ directives. Open Command Palette, search Preferences: Configure User Snippets, choose markdown.json, and add:

markdown.json 
{
  "Markup+ Note": {
    "prefix": "note",
    "body": ["@note", "$1", "@end"],
    "description": "Markup+ note block"
  },
  "Markup+ Warning": {
    "prefix": "warning",
    "body": ["@warning", "$1", "@end"],
    "description": "Markup+ warning block"
  },
  "Markup+ Tip": {
    "prefix": "tip",
    "body": ["@tip", "$1", "@end"],
    "description": "Markup+ tip block"
  },
  "Markup+ Danger": {
    "prefix": "danger",
    "body": ["@danger", "$1", "@end"],
    "description": "Markup+ danger block"
  },
  "Markup+ Success": {
    "prefix": "success",
    "body": ["@success", "$1", "@end"],
    "description": "Markup+ success block"
  },
  "Markup+ Variable": {
    "prefix": "let",
    "body": ["@let ${1:name} = \"${2:value}\""],
    "description": "Markup+ variable definition"
  },
  "Markup+ If": {
    "prefix": "if",
    "body": ["@if ${1:condition}", "$2", "@endif"],
    "description": "Markup+ conditional block"
  },
  "Markup+ Each": {
    "prefix": "each",
    "body": ["@each ${1:item} in ${2:list}", "$3", "@end"],
    "description": "Markup+ loop block"
  },
  "Markup+ Component": {
    "prefix": "def",
    "body": ["@def ${1:Name}(${2:args})", "$3", "@end"],
    "description": "Markup+ component definition"
  },
  "Markup+ Chart": {
    "prefix": "chart",
    "body": [
      "@chart(type=\"${1|bar,line,pie,doughnut|}\" title=\"${2:Title}\")",
      "data: [${3:1, 2, 3}]",
      "labels: [\"${4:A, B, C}\"]",
      "@end"
    ],
    "description": "Markup+ chart"
  },
  "Markup+ Tabs": {
    "prefix": "tabs",
    "body": ["@tabs", "@tab \"${1:Tab 1}\"", "$2", "@end", "@end"],
    "description": "Markup+ tab group"
  },
  "Markup+ Collapse": {
    "prefix": "collapse",
    "body": ["@collapse", "@item \"${1:Title}\"", "$2", "@end", "@end"],
    "description": "Markup+ accordion"
  },
  "Markup+ TOC": {
    "prefix": "toc",
    "body": ["@toc"],
    "description": "Markup+ table of contents"
  }
}

Now typing note and pressing Tab expands to a note block. Same for warning, tip, if, each, chart, etc.

Build tasks

Create a VS Code task to convert the current file with one keystroke. Add this to .vscode/tasks.json in your project:

tasks.json 
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "Markup+: Build current file",
      "type": "shell",
      "command": "npx markup-plus-js ${file}",
      "problemMatcher": [],
      "group": {
        "kind": "build",
        "isDefault": true
      }
    },
    {
      "label": "Markup+: Watch current file",
      "type": "shell",
      "command": "npx markup-plus-js watch ${file}",
      "problemMatcher": [],
      "isBackground": true
    },
    {
      "label": "Markup+: Check current file",
      "type": "shell",
      "command": "npx markup-plus-js check ${file}",
      "problemMatcher": []
    }
  ]
}

Then bind them to keyboard shortcuts in keybindings.json:

keybindings.json 
[
  {
    "key": "ctrl+alt+b",
    "command": "workbench.action.tasks.runTask",
    "args": "Markup+: Build current file",
    "when": "editorLangId == markdown"
  },
  {
    "key": "ctrl+alt+w",
    "command": "workbench.action.tasks.runTask",
    "args": "Markup+: Watch current file",
    "when": "editorLangId == markdown"
  },
  {
    "key": "ctrl+alt+c",
    "command": "workbench.action.tasks.runTask",
    "args": "Markup+: Check current file",
    "when": "editorLangId == markdown"
  }
]

Live preview workflow

A practical setup for editing .mup with live preview:

  1. Open a terminal and start the watch mode: 
    npx markup-plus-js watch hello.mup
  2. Open the generated hello.html in VS Code.
  3. Right-click it and choose Open with Live Server.
  4. Edit hello.mup — the HTML rebuilds on save, Live Server reloads the browser.

  1. Open Settings → Editor → File Types.
  2. Select Markdown.
  3. Add *.mup to the Registered Patterns.

15. Git integration

Tell Git to treat .mup files as Markdown for diffs and syntax highlighting on GitHub:

.gitattributes 
*.mup linguist-language=Markdown
*.mup diff=markdown
*.mup text eol=lf

Place this at the root of your repository. GitHub will now show .mup files with proper syntax highlighting.

16. Recommended .gitignore

For projects that generate HTML from .mup files, add this to .gitignore:

.gitignore 
# Markup+ generated output
*.html
!index.html

# Dependencies
node_modules/

# Build output
dist/

# Logs
*.log
Note

If you want to keep generated HTML in the repository (e.g. for GitHub Pages), remove the *.html line.

17. Recommended project layout

A typical Markup+ project:

Folder structure 
my-project/
├── docs/
│   ├── index.mup
│   ├── guide.mup
│   └── api.mup
├── assets/
│   ├── style.css
│   └── logo.png
├── build/
│   ├── index.html       (generated)
│   └── guide.html       (generated)
├── .gitattributes
├── .gitignore
├── package.json
└── README.md

Convert everything in docs/:

Batch convert 
# Windows
for %f in (docs\*.mup) do mup-js "%f" -o "build\%~nf.html"

# macOS / Linux
for f in docs/*.mup; do
  mup-js "$f" -o "build/$(basename "$f" .mup).html"
done

18. npm scripts setup

Add these scripts to package.json for common tasks:

package.json 
{
  "scripts": {
    "build": "mup-js docs/index.mup -o build/index.html",
    "watch": "mup-js watch docs/index.mup -o build/index.html",
    "check": "mup-js check docs/index.mup",
    "new": "mup-js new docs/draft",
    "init": "mup-js init"
  }
}

Then run npm run watch while editing.

19. CI/CD setup

Example GitHub Actions workflow that builds Markup+ files on every push:

.github/workflows/build-docs.yml 
name: Build Markup+ docs

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Install Markup+
        run: npm install -g markup-plus-js

      - name: Build all .mup files
        run: |
          for f in docs/*.mup; do
            mup-js "$f" -o "build/$(basename "$f" .mup).html"
          done

      - name: Upload build
        uses: actions/upload-artifact@v4
        with:
          name: docs-html
          path: build/

20. Environment variables

Markup+ respects a few environment variables:

Variable Effect
NO_COLOR Disable colored CLI output
FORCE_COLOR Force colored output even when not a TTY
DEBUG Enable debug logging in CLI
Disable colors 
# Windows (CMD)
set NO_COLOR=1
mup-js hello.mup

# Windows (PowerShell)
$env:NO_COLOR=1
mup-js hello.mup

# macOS / Linux
NO_COLOR=1 mup-js hello.mup
