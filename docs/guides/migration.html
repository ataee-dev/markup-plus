Migrating from Markdown

Markup+ is a strict superset of Markdown. Every .md file works as a .mup file — you can migrate incrementally, one feature at a time, without rewriting anything.

No rewrite required

You don't need to convert your existing Markdown files. Just run them through Markup+ — they'll work exactly as before, with the option to add new features over time.

What works out of the box

Everything in standard Markdown works identically in Markup+:

Markdown features that differ

Most Markdown works identically. A few features are enhanced in Markup+:

Feature Markdown Markup+
Tables Basic Same syntax + alignment + formatting
Images Basic Same syntax + captions, width, alignment, gallery, lightbox
Code blocks Basic Same syntax + titles, line numbers, line highlighting, run button
Links Basic Same syntax + `target="_blank"` automatically
Task lists Extension Native support
Footnotes Extension Native support

Compatibility guarantees

Concern Answer
Will my existing Markdown still render?Yes — every Markdown file works as a Markup+ file
Do I need to change syntax?No — migration is optional
Can I mix Markdown and Markup+?Yes — they coexist in the same file
Can I convert Markup+ back to Markdown?Markdown export is planned for a future version
Will Markdown-specific extensions break?No — all common extensions are supported
Can I use both renderers side by side?Yes — keep your old renderer and add Markup+ for new files

Migration best practices

  1. Don't rewrite everything — start with one file, migrate incrementally
  2. Keep .md if it works — rename later if you want
  3. Add features when they help — variables for repeated values, tabs for multi-language code
  4. Test with real content — some Markdown renderers have quirks that Markup+ handles differently
  5. Use the CLI for batch operations — convert an entire docs/ folder at once
  6. Keep your old renderer around — Markup+ works alongside any other tool
  7. Watch for edge cases — nested lists and complex tables may render differently

Common issues

Problem Cause Fix
Nested lists not rendering Not yet supported in v0.6.4 Flatten the lists, or use flat bullets
HTML tags showing as text HTML escaping is stricter Use Markup+ syntax instead of raw HTML
Table cell alignment differs Alignment defaults to left Add explicit :---: or ---:
Footnotes not working Syntax variations across Markdown flavors Use [^1] and [^1]: text syntax
Front matter parsed as content Must start at first line Ensure --- is the very first line
