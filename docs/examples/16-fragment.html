Fragment

renderFragment produces an inline HTML fragment without the full page wrapper. Perfect for chatbots, widgets, and embedding Markup+ content in existing pages.

Fragment vs full page

toHTML produces a complete page (<html>, <head>, <body>). renderFragment produces only the body content, scoped with custom classes so it does not interfere with the host page.

Scoped styling

Fragments are scoped — no interference with the host page:

OptionEffect
scoped: trueAll CSS is prefixed with a unique class (default)
scoped: falseCSS is included as-is (may conflict with host)

Fragment options

OptionTypeDescription
themestringTheme name for styling
scopedbooleanIsolate CSS (default: true)
includeScriptsbooleanInclude interactive scripts (tabs, collapse)
includeCDNScriptsbooleanInclude Prism, KaTeX, Chart.js from CDN

API example

Usage in JavaScript:

renderFragment API 
import { renderFragment } from 'markup-plus-js';

const response = `
# Answer

Here is a **formatted** response.

@tip
This is a tip block.
@end
`;

document.getElementById('chat').innerHTML = renderFragment(response, {
  theme: 'light',
  scoped: true,
  includeScripts: true,
  includeCDNScripts: true
});
