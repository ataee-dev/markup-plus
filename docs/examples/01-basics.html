Basics

Everything you know from Markdown works in Markup+. This page covers the fundamental building blocks: headings, paragraphs, text formatting, lists, and links.

Tip

If you already know Markdown, you can skip most of this page — Markup+ is a strict superset. Just skim the Markup+ Exclusive sections to see what's new.

Headings

Use # symbols to create headings. The number of # signs determines the level, from H1 (largest) to H6 (smallest).

Headings 
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6
Note

Each heading automatically gets an id attribute based on its text, so you can link to it: [Jump to Headings](#headings).

Paragraphs

Separate paragraphs with a blank line. Markup+ automatically wraps them in <p> tags.

Paragraphs 
This is the first paragraph.

This is the second paragraph, separated by a blank line.

And this is a third one.

Text Formatting

Markup+ supports the standard inline formatting from Markdown:

  • **bold** → bold
  • *italic* → italic
  • ~~strikethrough~~ → strikethrough
  • `code` → code
Text Formatting 
This is **bold** and this is *italic*.

You can combine: **bold with *italic* inside**.

This is ~~strikethrough~~ text.

And this is `inline code` in a sentence.

Special characters like <, >, & are escaped safely.

Lists

Unordered Lists

Use -, *, or + at the start of a line:

Unordered List 
- First item
- Second item with **bold**
- Third item with `code`
- Fourth item with *italic*

Ordered Lists

Use numbers followed by a period:

Ordered List 
1. Install Python
2. Install Markup+
3. Write a `.mup` file
4. Run `mup file.mup`
5. Open the HTML output

Links

Create links with [text](url). Add an optional title with [text](url "title").

Links 
Simple link: [Google](https://google.com)

Link with title: [Markup+](https://github.com/ataee-dev/markup-plus "Main repo")

Autolink: <https://example.com>

Combined with formatting: [**Bold link**](https://example.com)

Blockquotes

Use > at the start of a line:

Blockquotes 
> This is a simple blockquote.
> It can span multiple lines.

> **Bold in quote** with *italic* and `code`.

Horizontal Rules

Three or more dashes, asterisks, or underscores on their own line:

Horizontal Rules 
Above the line.

---

Between lines.

***

Below everything.

Summary

You've learned the fundamental Markup+ syntax:

Feature Syntax
Heading 1–6 # to ######
Bold **text**
Italic *text*
Strikethrough ~~text~~
Inline code `code`
Unordered list - item
Ordered list 1. item
Link [text](url)
Blockquote > quote
Horizontal rule ---
