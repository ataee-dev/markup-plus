Gallery

Group images into a responsive grid with an interactive lightbox. Click any image to open it full-size with keyboard navigation.

Why galleries?

Showcase multiple images in a compact, responsive grid. The lightbox lets users zoom without leaving the page.

Gallery syntax

PartDescription
@gallery {columns=N}Start a gallery with N columns (1-6)
![alt](url)Add an image
{caption="..."}Optional caption
{desc="..."}Optional description (shown in lightbox)
@endClose the gallery

Keyboard shortcuts

When the lightbox is open:

KeyAction
← / →Previous / next image
EscClose lightbox
Click outsideClose lightbox

Common errors

MistakeFix
Missing @endEvery @gallery must close with @end
Columns not specifiedDefault is 3, but explicit is better: {columns=3}
Images without !Use ![alt](url) not [alt](url)
Broken image URLsUse absolute URLs or verify relative paths
