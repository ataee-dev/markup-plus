Docs/Examples/Conditionals

Conditionals

Show or hide content based on conditions. Use @if, @elif, @else, and @endif to build dynamic documents.

Why conditionals?

Build one document that adapts to different environments, versions, or user roles — without duplicating content.

Basic if

The simplest form: show content only if a condition is true.

Basic conditional

If / Else

Provide an alternative when the condition is false.

If / Else

If / Elif / Else

Chain multiple conditions with @elif. The first matching branch is rendered.

If / Elif / Else

Operators

Markup+ supports the following comparison operators inside @if and @elif:

OperatorMeaningExample
==Equal@if version == "0.6.4"
!=Not equal@if status != "done"
>Greater than@if count > 10
<Less than@if count < 5
>=Greater or equal@if score >= 90
<=Less or equal@if score <= 50

Boolean conditions

If the variable itself is boolean, use it directly:

SyntaxMeaning
@if is_activeTrue if is_active is true
@if not_doneTrue if not_done is true

Common errors

MistakeFix
Missing @endifEvery @if must close with @endif
@if x = 5Use == for comparison, not =
@if x == 5 ... @endUse @endif, not @end
@if Name == "x"Case-sensitive: use the exact variable name
Comparing string to number"5" and 5 are different types
