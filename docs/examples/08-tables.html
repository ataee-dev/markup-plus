Tables

Markdown-style tables with left, center, and right alignment. Tables support inline formatting, links, and code.

Why tables?

Present structured data clearly. Markup+ tables support alignment, formatting, and links — all with Markdown-compatible syntax.

AlignmentSeparatorResult

Center:---:Text centered in cell
Right---:Text ends at right edge

Common errors

MistakeFix
Missing separator rowEvery table needs a --- row after the header
Uneven columnsAll rows should have the same number of pipes
Pipes in cell contentEscape with \\| or use inline code
No leading/trailing pipeRecommended for clarity, though not required
Empty cellLeave two pipes together: ||

Limitations in v0.6.4

Known limitations

Markup+ JS v0.6.4 does not support @each or @if inside tables. For dynamic tables, generate content outside the table or build HTML directly.
