Charts

Create bar, line, pie, and doughnut charts with the @chart directive. Charts use Chart.js and are rendered at build time.

Why charts?

Present data visually without writing JavaScript. Markup+ generates the Chart.js configuration from simple data arrays.

Chart syntax

PartDescription
@chart(type="...")Start a chart block. Type: bar, line, pie, doughnut
title="..."Optional chart title
data: [...]Array of numbers
labels: [...]Array of strings
@endClose the chart block

Chart types

TypeBest forExample
barComparing categoriesSales by region
lineTrends over timeUser growth
pieParts of a wholeMarket share
doughnutParts of a whole (with hole)OS distribution

Common errors

MistakeFix
Missing @endEvery @chart must close with @end
String in dataUse numbers: data: [1, 2, 3] not [1, "2", 3]
Missing bracketsdata: 1, 2, 3 is wrong — use data: [1, 2, 3]
Mismatched lengthsdata and labels must be the same length
Unknown typeOnly bar, line, pie, doughnut

Summary

TaskSyntax
