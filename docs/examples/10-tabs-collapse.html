Tabs & Collapse

Organize content with tabs for alternative views, and collapsible sections for optional details. Both are interactive and work without JavaScript on the user's side.

When to use each

Use tabs when content is alternative (e.g., install on Windows / macOS / Linux). Use collapse when content is optional or for FAQs.

Tabs

Group alternative content into clickable tabs:

Tab group with code samples

Tabs syntax

DirectivePurpose
@tabsStarts a tab group
@tab "Title"Starts a single tab with the given title
@endCloses a tab or the whole group
Nesting rule

Each tab closes with @end, then the whole group closes with another @end. Two @end per group of tabs (except the last one also closes the group).

DirectivePurpose

@endCloses an item or the whole group

Common errors

MistakeFix
Missing @end for tabEvery @tab closes with @end
Missing @end for groupThe whole @tabs closes with another @end
@tab Python (no quotes)Tab titles must be quoted: @tab "Python"
Tabs inside a tableTabs must be on their own lines
Content outside tabs after @endMake sure you close the group with @end
Nested @tabs in @tabNesting tabs works — make sure each closes correctly

Summary

ComponentSyntax
Tabs group@tabs @tab "A" ... @end @tab "B" ... @end @end
Collapse group@collapse @item "A" ... @end @item "B" ... @end @end
NestedTabs inside tabs, collapse inside collapse, or cross-nested
Default openFirst tab is active; all collapse items start closed
