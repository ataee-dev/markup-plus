Components

Define a block once with @def, then use it as many times as you want with @Name(...). Perfect for repeated structures like cards, alerts, and user profiles.

Why components?

Change the definition once, and every usage updates. Ideal for cards, callouts, user info blocks, and repeated UI patterns.

Basic component

Define a component with @def Name(param1, param2) ... @end. Call it with @Name(param1="value", param2="value").

Boolean argument@Name(x=true)

Naming rules

  • Component names must start with an uppercase letter (PascalCase).
  • Argument names must be lowercase or camelCase.
  • Arguments are separated by commas.
  • Use {arg} inside the component body to reference arguments.
  • Components can call other components (nested components).
  • Component arguments can be values from outer variables.
