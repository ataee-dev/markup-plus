Alerts

Five alert types for different purposes: @note, @warning, @tip, @danger, and @success. Use them to draw attention to important content.

Why alerts?

Draw attention to important information without breaking the reading flow. Each alert type has a distinct color and icon for quick scanning.

All alert types

Markup+ supports five alert types. Each has its own color and semantic meaning:

All alert types

Alert reference

Alert Color Use for
@note Blue Additional information that supplements the main content
@warning Yellow Potential issues, precautions, important considerations
@tip Green Helpful hints, shortcuts, best practices
@danger Red Critical warnings, destructive operations, data loss risks
@success Green Confirmations, positive results, completed operations

Use notes for supplementary information — details that aren't essential but add context.
