Loops

Repeat content for each item in a list. Loops combined with conditionals and components make Markup+ documents truly dynamic.

Why loops?

Generate lists, tables, and repeated blocks from data. Change the data, and the output updates automatically.

Basic loop

The syntax is @each item in list ... @end. The loop variable is available inside the block.

Loop with index

Get the position of each item with @each i, item in list. The index starts at 1.

Common errors

MistakeFix
Missing @endEvery @each must close with @end
@each in listSpecify the loop variable: @each item in list
@each x in "text"The list must be an array, not a string
@each i, x in list orderIndex comes first: i, item
Loop variable used outside the blockLoop variables only exist inside the loop

Summary

TaskSyntax
Simple loop@each item in list ... @end
With index@each i, item in list ... @end
With condition@each item in list ... @if cond ... @endif ... @end
