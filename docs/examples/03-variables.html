Variables

Variables let you store reusable values in your Markup+ documents. Define once, use everywhere. Combine with filters to transform values on the fly.

Why variables?

Change a value once and it updates everywhere it's referenced. Perfect for versions, project names, dates, and repeated content.

Basic Variables

Define a variable with @let name = "value". Use it anywhere with {name}.

Practical Example

Variables are most useful for metadata that appears in multiple places. Here's a document with a version number referenced multiple times:

Version metadata 
@let project = "Markup+ JS"
@let version = "0.6.4"
@let author = "Hossein Ataee"

# {project}

**Version:** {version}
**Author:** {author}

## Changelog

### v{version} — Current

- Added variables
- Added filters
- Added conditionals

@note
Version {version} is the latest release.
@end

Change @let version = "0.6.4" once, and every occurrence updates automatically.

Scoping rules

  • Variables are defined with @let and are visible from that point forward in the document.
  • Variables defined inside @each or @if blocks are scoped to that block.
  • Loop variables from @each item in list shadow any outer variable named item.
  • Front matter fields (between --- lines) become variables too.
