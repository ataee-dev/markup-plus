Docs/Examples/CLI

CLI

The mup-js command-line tool converts .mup files to HTML, validates documents, initializes projects, and watches files for changes.

Why CLI?

Convert documents, build sites, and integrate Markup+ into build pipelines. No JavaScript required.

Installation

Install globally to use mup-js from anywhere:

Global install 
npm install -g markup-plus-js

Or run it once without installing:

One-off run 
npx markup-plus-js hello.mup

Verify the installation:

Verify 
mup-js --version
# Markup+ JS v0.6.4

Commands

Command Description
mup-js <file>Convert .mup file to HTML
mup-js watch <file>Watch file and rebuild on change
mup-js new <name>Create a new .mup file
mup-js open <file>View file in terminal
mup-js check <file>Validate file for errors
mup-js init [name]Create a new project
mup-js --helpShow help
mup-js --versionShow version

Convert a document

The most common operation — convert a .mup file to HTML:

Basic convert 
mup-js hello.mup
# Creates hello.html in the same folder

Watch mode

Automatically rebuild on every file save:

Watch mode 
mup-js watch hello.mup

# Output:
# Watching for changes...
# Input:  hello.mup
# Output: hello.html
# Press Ctrl+C to stop.

# On each save:
# [time] Change detected, rebuilding...
# Rebuilt -> hello.html

Create a new document

Generate a starter .mup file:

New document 
mup-js new my-doc
# Creates my-doc.mup with starter content

mup-js new my-doc.mup
# Same result — extension is added automatically

Validate a document

Check for errors before building:

Validate 
mup-js check hello.mup

# Checks for:
# - Undefined variables
# - Unbalanced blocks (@if without @endif)
# - Empty documents

Initialize a project

Create a project structure with folders and starter files:

Init project 
mup-js init my-project
# Creates:
# my-project/
# ├── docs/
# ├── assets/
# └── index.mup

View in terminal

Preview a .mup file directly in your terminal with syntax highlighting:

Open in terminal 
mup-js open hello.mup

Examples

Combined usage:

Combined options 
# Dark theme
mup-js report.mup --dark

# With specific theme
mup-js report.mup --theme dracula

# Force RTL
mup-js persian.mup --rtl

# Custom output path
mup-js input.mup -o build/index.html

# Custom CSS
mup-js document.mup --css my-style.css

# Fragment for chatbot
mup-js response.mup --inline --with-scripts --with-cdn

# Debug mode
mup-js complex.mup --debug

Scripting

Use the CLI in build pipelines:

package.json scripts 
{
  "scripts": {
    "docs:build": "mup-js docs/index.mup -o build/index.html",
    "docs:watch": "mup-js watch docs/index.mup -o build/index.html",
    "docs:check": "mup-js check docs/index.mup"
  }
}

Then run:

Run scripts 
npm run docs:build
npm run docs:watch

Batch conversion

Convert all .mup files in a folder:

Batch (Windows) 
for %f in (docs\*.mup) do mup-js "%f" -o "build\%~nf.html"
Batch (macOS/Linux) 
for f in docs/*.mup; do
  mup-js "$f" -o "build/$(basename "$f" .mup).html"
done

Common errors

ErrorFix
mup-js: command not foundAdd npm global bin to PATH, or use npx
File not foundCheck that the file path is correct
Cannot find moduleReinstall: npm install -g markup-plus-js
Watch mode doesn't rebuildSome editors save atomically — try saving again
Output is emptyInput file may be empty — run mup-js check
