Themes

Markup+ ships with 12 built-in themes plus support for custom CSS. Themes control colors, fonts, and visual styling of the generated HTML.

Why themes?

Change the entire look of your document with one option. Use a light theme for documentation, dark for code-heavy content, or a specialized theme for a specific brand.

How to use a theme

Set the theme in the render options:

Theme option 
import { toHTML } from 'markup-plus-js';

const html = toHTML(source, {
  theme: 'dracula'
});

Or from the CLI:

CLI 
mup-js hello.mup --theme dracula

Auto dark mode

Uses the user's prefers-color-scheme setting:

Auto dark 
const html = toHTML(source, {
  theme: 'light',
  autoDarkMode: true,
  darkTheme: 'dracula'
});

Custom CSS

Override any style with your own CSS:

Custom CSS 
:root {
  --mup-accent: #ff6b6b;
  --mup-bg: #1a1a2e;
  --mup-text: #eaeaea;
  --mup-font-family: 'Inter', sans-serif;
  --mup-max-width: 900px;
}
