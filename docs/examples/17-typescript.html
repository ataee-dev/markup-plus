TypeScript

Markup+ JS ships with complete TypeScript definitions. No @types/ package needed — types are bundled with the package.

Why TypeScript?

Full IntelliSense, autocomplete, and type checking in your editor. Catch mistakes before they reach production.

Basic usage

Types work out of the box. Import and use functions with full type safety:

Basic TypeScript 
import { toHTML, Theme, RenderOptions } from 'markup-plus-js';

const theme: Theme = 'dracula';
const options: RenderOptions = { theme };

const html: string = toHTML('# Hello', options);
console.log(html);

Using the Theme type

The Theme type restricts values to valid theme names:

Theme type 
import { toHTML, Theme } from 'markup-plus-js';

// Type-safe: valid themes only
const theme1: Theme = 'dracula';      // OK
const theme2: Theme = 'light';        // OK
// const theme3: Theme = 'invalid';   // Error at compile time

// Using a theme variable
function render(content: string, theme: Theme): string {
  return toHTML(content, { theme });
}

Working with AST

Parse and traverse the document tree with full type support:

AST traversal 
import { parse, Document, Heading, Paragraph } from 'markup-plus-js';

const doc: Document = parse('# Hello\n\nWorld');

for (const node of doc.children) {
  if (node instanceof Heading) {
    console.log('Heading level:', node.level);
    console.log('Text:', node.text);
  } else if (node instanceof Paragraph) {
    console.log('Paragraph:', node.text);
  }
}

Recommended tsconfig

For best results, use these settings:

tsconfig.json 
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "types": []
  }
}
