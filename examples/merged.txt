## ✨ Features

Markup+ is more than Markdown. It includes:

- **Variables** — `@let name = "Ali"`
- **Filters** — `{name|upper}`
- **Conditionals** — `@if` / `@elif` / `@else`
- **Loops** — `@each item in items`
- **Components** — reusable blocks
- **Charts** — bar, line, pie, doughnut
- **Math** — via KaTeX
- **Tabs** & **Accordions**
- **Alerts** — note, warning, tip, danger, success
- **Auto RTL** — Persian, Arabic, Hebrew

```html {title="preview.html"}
<!DOCTYPE html>
```

```html
<head>
    <style>
        body { font-family: sans-serif; padding: 20px; }
        .card {
            background: linear-gradient(135deg, #7c3aed, #ec4899);
            color: white;
            padding: 20px;
            border-radius: 12px;
        }
    </style>
</head>
<body>
    <div class="card">
        <h1>پیش‌نمایش زنده!</h1>
        <p>این HTML به‌صورت زنده رندر می‌شود.</p>
    </div>
</body>
</html>
```
